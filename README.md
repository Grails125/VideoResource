## 使用

在映川「设置 → 站源管理 → 添加 → 配置订阅」选择分类，或填写对应地址；读取预览后确认导入。更新已有配置时检查差异并明确确认，个人停用选择、来源身份、权限与观看下载资料由客户端管理。

四份订阅统一使用 `cache_time: 7200` 与 `api_site` 外层结构。普通采集接口使用 HTTP／HTTPS；原生来源通过客户端已支持的稳定适配器接入，可选配置使用 `native.version: 1`。仅使用客户端内置配置的影视2适配器可不提供 `native` 覆盖。

## 维护与校验

- 每个稳定来源键及接口身份只在一份订阅中维护。新增前检查键、适配器或规范化接口地址与独立详情配置，去重后追加到对应文件末尾；保留其他条目的内容和顺序。
- URL 去重仅统一主机大小写、默认端口、末尾斜线和 `ac=list`，保留其他查询参数、转义路径、HTTP／HTTPS 及独立详情配置。
- 来源显示名保留站名文字、真实数字和英文大小写，移除装饰符号及测速延迟；有意义的括号内容转为普通文字。原有明确成人标记使用“成人 ”文字前缀。校验器拒绝再次混入装饰或延迟，只报告同名来源，不按名称合并接口或自动改名。
- 所有发布来源默认启用；检查失败只记录结果，不自动禁用来源。不提交账号、Cookie、密钥、个人配置、媒体或站源图片。
- 不新增其他 JSON 文件。来源数量变化时同步更新本文及校验脚本中的分类数量；旧内容需要追溯时查看 Git 历史。

在仓库根目录执行：

```sh
python -B scripts/check_subscriptions.py
python -B scripts/test_check_subscriptions.py
python -B -m unittest discover -s scripts -p 'test_*.py'
```

校验器检查仅有四份订阅 JSON、外层结构与字段类型、各分类数量、稳定键和接口去重、显示名格式、公开 HTTP／HTTPS 地址、原生适配器身份及版本、默认启用状态与明确成人标记的分类，并报告同名来源。当前四份配置共 207 项通过这些离线检查；配置校验 23 项、健康检测 26 项、解码工具准备 9 项，共 58 项测试通过。

这些检查不请求站源图片、账号或媒体，也不等同于当前站点可用性、真实播放、完整原生配置行为或物理设备验收；来源访问条件仍由对应服务决定，不绕过 TLS、登录、付费、DRM 或访问拒绝。

## 每日在线检测

[检测工作流与网页手动运行入口](https://github.com/yingchuan-media/yingchuan-sources/actions/workflows/source-health.yml)。工作流进入默认分支后，计划每天 **06:17（香港时间，UTC+8）**运行；GitHub 定时任务可能排队延迟，公开仓库长期无活动时也可能停用计划。拥有仓库写入权限的维护者可打开该页面，点击 **Run workflow**，选择默认分支再运行。其他分支的手动运行只生成运行摘要和报告 artifact，不写回默认分支。

脚本使用 Python 3.12+ 标准库；本地首帧检测和合成首帧回归另需 PATH 中的 FFmpeg。工作流在隔离的只读检测 job 中准备固定的 Linux x64 FFmpeg，记录其实际构建版本。测试只使用合成元数据和合成媒体，不访问站源。在线阶段每站只抽样目录第一页的第一条有效记录：

- **目录**：请求标准 JSON／XML 采集列表，校验媒体身份与非空列表；需要时补全同一 ID 的详情。保留接口中其他有语义的查询参数及转义路径。
- **封面**：仅向抽样记录的封面地址发送 HEAD，核对状态及图片 Content-Type；不发送 GET、不读取图片正文、不验证图片解码。拒绝 HEAD 或返回封装类型时不能证明图片无效。
- **搜索**：以抽样片名搜索，要求结果包含同一 ID 或相同名称。只检查一次搜索请求，不测试全量分页。
- **能否播放**：选第一条线路的第一集，探测实际响应；HLS 最多解析三层，仅读一个完整片段入口和必要 init，单个媒体样本最多 1 MiB，以只允许 pipe 输入的 FFmpeg 尝试解码一个视频帧。网页解析、DASH、加密或字节范围 HLS 标为未验证；不获取授权、Cookie、密钥或其他线路。
- **延迟**：目录列为单次请求的实际耗时，其他检查单列耗时。包括 DNS、连接、TLS 及有界正文读取，不是 ICMP ping、吞吐量、平均值或用户设备测量；失败耗时仍保留并标明失败。

189 项标准采集接口使用上述检测。18 项原生适配器依赖客户端特有协议，四项明确标为“原生协议需客户端验证”，不把首页 HTTP 200 当成目录、搜索或播放成功。目录不可用时，后续依赖项标为未检测。首帧未解码只说明本次有界抽样失败，可能受片段大小、MP4 索引位置、地域或运行节点访问条件影响，不自动判定全站失效。

默认最多 6 站并行，每请求 8 秒、每站网络阶段 50 秒及 16 次请求预算，首帧解码另限 10 秒；DNS 解析使用系统解析器，工作流另设 35 分钟总上限。无自动重试、线路轮换、挑战破解或降级 TLS；公网 DNS 结果固定到本次连接，重定向重新校验并拒绝私网地址及 HTTPS 降级。响应正文、媒体样本只保留在进程内存，不写入仓库或 artifact。检测失败只更新结果，不修改订阅、排序、名称或启停状态。任务执行错误不会覆盖上次报告。
