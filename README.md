在客户端进入“设置 → 站源管理 → 添加 → 配置订阅”，选择分类或填写上表地址，读取预览后确认导入。首次导入只新增，更新已有配置需要检查差异并确认；个人停用、账号权限及观看下载资料由客户端管理。

四份订阅使用 `cache_time: 7200` 与 `api_site` 外层结构。普通采集接口使用公开 HTTP／HTTPS 地址，可选原生来源使用客户端支持的稳定适配器及 `native.version=1`。客户端内置来源不应再次导入。

## 维护规则

- 固定使用影视、短剧、动漫、未知四类，不新增合集、索引或归档订阅。内容范围待确认的来源保留在未知类。
- 新增项按稳定键、适配器及规范化接口地址与独立详情配置去重，追加到对应文件末尾，保留既有身份和顺序；不按名称合并接口。
- URL 只统一主机大小写、默认端口、末尾斜线和 `ac=list`，保留其他查询、转义路径、协议和独立详情配置。
- 显示名保留站名、真实数字及英文大小写，移除装饰、测速延迟与批次标签，不增加“成人 ”前缀；同名不同接口只报告，不自动改名。
- 所有发布配置默认启用，健康检查失败不自动禁用；已安装的个人停用选择由客户端保留。
- 不提交账号、Cookie、密钥、个人配置、媒体或图片正文，不绕过 TLS、登录、付费、DRM 或访问拒绝。

完整约束见 [AGENTS.md](AGENTS.md)。原有内容更新、迁类或协议变化应有明确任务依据，不以检测失败改写来源。

## 离线校验

```sh
python -B scripts/check_subscriptions.py
python -B scripts/test_check_subscriptions.py
python -B scripts/test_check_health.py
python -B scripts/test_setup_ffmpeg.py
```

校验范围包括四份 JSON、结构与字段、动态分类数量、256 项单文档上限、稳定键及接口去重、名称、公开地址、适配器身份与默认启用。合成回归不访问真实来源；原生检测器另使用固定客户端核心验证配置与协议闭环。
